# Инструкции для разработки

## Язык общения
- Всегда отвечай на русском языке
- Технические термины можно оставлять на английском, если это общепринятая практика

## Ориентация приложения
- Приложение поддерживает только горизонтальную (landscape) ориентацию
- Все UI компоненты должны быть спроектированы для горизонтальной ориентации
- В Info.plist должны быть установлены соответствующие настройки
- Constraints и layout должны учитывать landscape режим
